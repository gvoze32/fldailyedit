The Edit file is called EDIT00000000 and can be found in %HOMEPATH%\\Documents\\KONAMI\\eFootball PES 2021 SEASON UPDATE\%steamid%\\save.

It is encrypted and thus, cannot be simply edited directly.

Refer to the Tools page for decrypting and editing tools.

Note: This edit file mapping applies to Pro Evolution Soccer 2020 as well.

Limitations enforced by PES

Even though editing the save files externally technically allows using the full range of all values, PES puts some additional limitations in place.
Some of these might be checked and corrected by the game, others are just taken as they are.
This might lead to unexpected behaviour or even crash the game.
Be sure to check Appendix:Rules or the rules of the invitational in question to find out what is considered legal.
